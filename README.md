## Running the Website Locally

Clone the repository:

```bash
git clone https://github.com/engrmjdc/mackjohn-portfolio.git
```

Open the project:

```bash
cd mackjohn-portfolio
```

Open `index.html` in a browser.

You can also use the Visual Studio Code Live Server extension for automatic browser refresh while editing.
